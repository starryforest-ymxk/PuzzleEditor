# CLI C5 技术设计：备用 JSON 编辑与独立发行

日期：2026-10-09。状态：已按本设计完成并验收，见 [C5 实施报告](./CLI_C5_Implementation.md)。本文在实现前形成；基于 C1–C4 工作区继续，不覆盖既有改动，本批未提交推送 Git。

## 目标与授权

交付 `json preview/apply` 和 Windows x64 独立 CLI companion ZIP。用户已明确人工授权发生在外部 Agent 聊天中；Agent 判断授权的项目、任务及范围，范围内无需逐条重问。C5 开发中的虚构测试工程、候选和异常夹具属于本次实现验收，不修改用户业务工程。

`json apply` 必须显式携带 `--allow-raw-json-write`；缺少时退出 6，在读取项目或写文件前拒绝。该参数声明调用方已获得聊天授权，CLI 不读取/认证聊天内容、不签发批准凭据、不依赖审批窗口或桌面会话。普通命令不接受该参数，不自动降级到 JSON 写入。Agent 指引明确未授权、拒绝/撤回和超范围时不得使用备用写入。

## 输入、输出与唯一职责

- `contracts/automation/rawSchemas.ts`：两个请求与 `raw-json-preview` 回执；沿用版本、非空字符串和 SHA-256 原语。预览输入 source、candidate、out，可选 expectedHash/receiptOut；提交增加 receipt/allowRawJsonWrite。候选首版仅接受明确文件路径，避免 stdin 重放的不确定性。
- `services/automation/rawWriteService.ts`：完整源/候选快照、格式检查、预览差异与影响、回执一致性及排他发布。CLI 只做契约和输出适配。
- `candidateValidation.ts`：从现有 writeService 抽出同一业务错误基线策略，普通领域与备用 JSON 共用。以完整诊断身份计数，保留既有错误但拒绝新增错误与资产名清空。
- `rawPolicy.ts`：整文件前后比较资产命名和资源生命周期。用类型/所属/ID 匹配，局部变量迁移只在剩余同 ID 资源唯一匹配时识别。删除 Stage/Puzzle 不能顺带移除受保护的局部资源。新增资源仅 Draft；已实现/标删资源不能物理删除、退回 Draft 或换 ID 伪装新建。复用 `utils/resourceLifecycle.ts`，自动化附加限制放在该共享 owner。
- `fileCommit.ts` 和 Node IO：继续唯一维护路径别名/硬链接保护、排他创建、临时文件和写后重读；预览明确拒绝已有输出，apply 同字节重试只核验已交付文件。

## 原文保持与校验

源和候选均须是可结构化读取的完整 `puzzle-project`；保留完整只读对损坏/未来文件的支持，但此批不将不可识别结构直接写为有效工程。拒绝重复键、不安全数值、非法 UTF-8、未知结构字段和过深嵌套。

候选经现有导入器验证，在独立对象上检查其 project/editorState 与导入后的规范形态是否相同；比较时忽略对象键顺序与 JS 的 undefined，保留数组顺序。如需补默认值、迁移或修正，返回 `CANDIDATE_NORMALIZATION_REQUIRED`、完整变更和 notices，调用方形成新候选再预览。单纯 editorVersion 来源提示不阻断无变化的候选。

新建及显式修改 assetName 使用共用严格命名契约，未改的旧缺名可按现有基线保留。所有变量、脚本、引用、FSM、演出图和局部上下文仍走共同校验。raw 入口允许完整文件合法字段和 editorState 的明确调整，不限制为现有 42 种领域命令，也不执行脚本代码。

预览返回 source/candidate 指纹、完整 changes、impacts、diagnostics、remainingErrors、内容绑定回执及目标路径。回执含源/候选规范路径与原文字节 SHA-256、目标路径、写入方式 create-new、目标预期不存在。回执不证明聊天授权。修改任一输入必须重新预览；已有授权范围内无需重复询问。

提交重新读取并校验全部输入，匹配回执后在发布前再次核对源/候选/回执；只写候选原始 UTF-8 字节，保留 BOM、缩进、换行和时间字段，不重新序列化。输出不得与源/候选/回执别名或硬链接重合。不承诺锁住第三方程序；返回成功表示该快照的新副本交付，不操作 GUI 内存、历史或偏好。

## 独立发行

新增可重复执行的发行脚本、Node 运行时锁文件和隔离包验证脚本。固定 Node 24.15.0 win-x64（与本机已验证版本相同），从官方发行目录取得并锁定 SHA-256，打包前校验。ZIP 包含 CLI bundle、包类型声明、相对路径启动器、node.exe、Node/Zod 许可证、Agent 指南、命令/规则元数据、文件指纹清单与中文说明；不带开发依赖、源码、测试工程、用户数据或聊天内容。

输出仅在 release 下创建新的目录/ZIP，已存在时拒绝覆盖。启动器使用自身所在目录的运行时，保持调用方工作目录；不要求全局 Node，不更改 PATH。Windows 使用 PowerShell 压缩/展开明确路径，脚本校验目标边界；只清理自己创建且核对过的隔离临时目录。另提供 Node 入口供其他平台有兼容运行时的调用方使用；本批不声称已交付其他平台原生运行包。

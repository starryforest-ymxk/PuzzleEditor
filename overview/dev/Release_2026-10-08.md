# Windows Release 打包与 Git 提交（2026-10-08）

## 目标和范围

将已完成的六批架构修复、未保存关闭保护、弹窗及六类 UI 统一打包为 Windows x64 NSIS 安装包，并提交、推送到 `origin/main`。沿用当前 `package.json` 的 `1.0.0-beta`，生产构建不等同于宣布稳定版。

现有 `release/` 中保留 2026-03-04 的同版本产物。新产物放在 `release/2026-10-08/`，避免覆盖；安装包和解包程序继续由 `.gitignore` 排除。保持仓库既有的 `dist-electron` 跟踪方式，提交与 TypeScript 源码对应的编译产物。

## 执行设计

1. 核对当前源码、配置、版本和远端；检查待提交文件及凭据模式。远端同步后，本地与 `origin/main` 为 0 / 0，不需要合并。
2. 执行 `npm run check`，涵盖编码、strict 类型、lint、格式、UI 单一维护入口、反向探针及全部回归。执行 `npm run test:electron` 验证真实 IPC 与关闭保护。
3. 使用现有构建链 `npm run electron:build -- --win --x64 --publish never --config.directories.output=release/2026-10-08`。Vite 生产页面使用相对路径；Electron 编译、预加载和生产依赖由现有 electron-builder 配置收纳。构建失败则停止提交并修复实际阻塞，不发布失败产物。
4. 对实际 `win-unpacked/Puzzle Editor.exe` 做隔离冒烟：从 ASAR 加载页面、预加载 API/IPC、恢复夹具、编辑及关闭确认、保存结果。用户偏好、项目和 Chromium 数据使用新临时目录，不使用真实工作项目。脚本位于 `tests/electron/run-packaged-smoke.mjs`，结果归入 `overview/dev/verification/`。
5. 检查安装包、blockmap、ASAR 清单及 SHA-256；记录实际验证和未覆盖的安装/签名边界。此前浏览器菜单、检查器、图编辑和弹窗的手工结果参见 UI 实施报告，不将自动化冒烟称为完整人工验收。
6. 同步本文及实现状态后，检查暂存区、提交所有已完成的修复和对应文档，再推送 `origin/main`。通过远端分支哈希确认推送，安装包以本地文件交付；本次不创建 GitHub Release。

## UX 验证对应

对应 `UX_Flow.md` 的项目控制、消息反馈、Stage/Node 导航和检查器编辑，重点核对桌面生产环境中项目恢复、编辑脏状态、保存持久化与退出保护。原有浏览器回归继续由测试和既有人工证据覆盖；不修改只读设计文档，也不扩展尚未完成的图缩放或 Unity 联调。

### 构建环境修复及复跑

首次 winCodeSign 解压因 Windows 无符号链接权限失败，涉及工具包的 macOS 动态库，未修改项目代码或系统权限。官方工具包 MD5 与下载响应提供的值一致，SHA-256 为 `cdaec7154dda7cc31f88d886e2489379a0625a737d610b5ae7f62a12f16743a4`。在独立的 `D:\Temp\puzzle-release-build-tools-20261008\winCodeSign\winCodeSign-2.6.0` 中提取非 darwin 内容，保留 rcedit/Windows 工具，并仅为该构建进程使用系统已有的本机代理；后续 NSIS 下载和构建成功。没有使用第三方镜像或关闭应用资源写入。

本机复跑可在 PowerShell 中执行：

```powershell
$env:ELECTRON_BUILDER_CACHE = 'D:\Temp\puzzle-release-build-tools-20261008'
# 仅在本机已有代理仍运行时使用；其他环境按实际网络配置。
$env:HTTPS_PROXY = 'http://127.0.0.1:7897'
$env:HTTP_PROXY = 'http://127.0.0.1:7897'
npm run electron:build -- --win --x64 --publish never --config.directories.output=release/2026-10-08
node tests/electron/run-packaged-smoke.mjs 'release/2026-10-08/win-unpacked/Puzzle Editor.exe'
```

冒烟脚本使用 [Electron 主进程调试接口](https://www.electronjs.org/docs/latest/tutorial/debugging-main-process) 在入口执行前设置独立数据目录；随后驱动生产 BrowserWindow 和 DOM，未替换保存服务或修改 ASAR。复跑会生成新的临时目录；再次打包会更新指定产物目录，保留版本请指定新输出目录。
